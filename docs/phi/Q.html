Related work

A map of published work around the Zeckendorf register, the Fibonacci Q-matrix and Fibonacci coding, in four domains: pure mathematics, hardware, coding, and adjacent number systems. It places phi among them; it is not a measurement, and the relevance mark on each node is this page's own reading.

  • What phi builds on.Zeckendorf's theorem, Fibonacci coding, the canonical signed digit form it compares against, and the rewrite rules of Zeckendorf arithmetic.
  • What phi does not build.Fibonacci hardware, a matrix register, negafibonacci or base-φ arithmetic: the code holds the one-dimensional register of phi_prune.register only.
  • What was checked.Each citation below was looked up; a claim no source could be found for is left out of the map.

The component builds the map up in four levels, each finding alone, then by domain, then across domains, then all of them on the matrix M = [[1, 1], [1, 0]]. Selecting a finding shows its detail and, beside it, the naive call tree of fib(n) annotated with that finding's quantity at each node: the Vajda sign, a Pisano residue, a continued-fraction ratio, the Fibonacci code length of F(k), the CSD Hamming weight of F(k), and so on.
