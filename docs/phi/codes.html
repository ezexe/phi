Fibonacci codes

phi writes integers in one prefix code, Fibonacci coding, which phi_prune.gaps holds. A pruned model's quantization levels and a model's delta between two checkpoints both go into files as Fibonacci codewords, with no length or separator written between them. Each file's header writes how many values each tensor holds and, where the bits are packed, how many bits the payload has, and the delta writes a sign digit before each value's codeword.

  • The codeword.The Fibonacci code of n ≥ 1 is the Zeckendorf representation of n, least significant digit first, followed by an appended 1.
  • The comma.A Zeckendorf representation never holds two adjacent 1s and its top digit is 1, so the appended 1 makes the first 11 of each codeword, the comma that ends it.
  • The users.export_bitstream writes each quantization level plus 1, and encode_delta writes the gaps between kept positions and each kept value's level plus 1.

Code a set of positions

This runs encode_positions and gap_bits in the page. Give strictly increasing positions from 0 and a tensor size. Each gap counts from the position before it, the first from −1, so every gap is at least 1 and has a codeword.

Read a stream

This runs read_codes in the page: it adds each 1's place value, ends a codeword at the first 11, and raises where the module raises, on a character other than 0 or 1 and on a stream that ends inside a codeword.

The code

fib_code(n) writes n with phi_prune.register.from_int on the place values 1, 2, 3, 5, 8, … and appends a 1. fib_code_length(n) is its length, and both refuse an n below 1.

codeword11011001110110001110011010110000111010110000011

A codeword is one digit longer than the Zeckendorf representation of n, whose length grows as logφ n, about 1.44 log2 n. The code is a prefix code: no codeword begins another, since each holds its single 11 at its end. It is a universal code, with no parameter fitted to the data. It is also known as a self-synchronizing code: the Fibonacci coding article notes that one changed bit can make a codeword read as two, or two as one, without spoiling what follows. Nothing in gaps.py or its tests measures this.

read_codes(bits, start, count) reads count codewords from start, or to the end, and returns the values and the index just past the last one. It raises ValueError when the bits end inside a codeword or before count codewords. encode_gaps and decode_gaps join and split a whole stream. tests/test_gaps.py holds the known codewords, the single 11 of each, the refusal of 0, round trips, and the refusal of a truncated stream and of unsorted or negative positions.

Gaps of a sorted list

A sparse set of positions is cheaper to write as the gaps between them. positions_to_gaps takes strictly increasing positions from 0 and returns their differences, the first counted from −1, and gaps_to_positions adds them back up. encode_positions and decode_positions chain the two with the code. top_positions(tensor, keep) picks what to keep: the sorted flat positions of the k largest entries of the tensor's absolute value, with k the fraction keep of its size rounded, at least 1, which is top-k sparsification. It refuses keep outside 0 to 1 and a tensor with no entries.

gap_bits(gaps, n_positions) prices one set of gaps in mean bits per kept position for each code it compares:

Quantization levels

FibonacciEncoder(n_digits) quantizes weights to integer levels whose Zeckendorf representations fit in n_digits digits. Those are every sum of non-adjacent place values among the first n_digits, which is every integer from 0 to F(n_digits + 2) − 1: 6 digits give 21 levels, the default 8 give 55, 10 give 144 and 12 give 377. encode_tensor is uniform affine quantization: it spreads the levels evenly between the smallest and largest kept weight, rounds each kept weight to the nearest level, ties going up, and returns the de-quantized weights, which is fake quantization, with the scale, levels per unit of weight, and the root-mean-square error. With axis each slice along that axis gets its own scale and quantization offset, which is per-channel quantization; without it one pair covers the tensor. levels inverts the scale-back to give each kept weight's integer level, and to_codeword gives a level's digits.

The pruning pipeline's exported bitstream writes each level plus 1 with encode_gaps, so level 0 becomes the codeword 11, and reads them back with read_codes. The digits of a level hold no two adjacent 1s, so the stream needs no lengths written.

The delta of a fine-tuned model

A model trained in rounds can ship each round as its delta, the new weights minus the base. phi_prune.delta writes one in Fibonacci codes:

header, payload = encode_delta(base.state_dict(), tuned.state_dict(), keep=0.01)
save_delta("round-07.phid", header, payload)
state = base.state_dict()
apply_delta(state, *load_delta("round-07.phid"))
base.load_state_dict(state)
  • What it keeps. In each floating tensor of the delta, encode_delta keeps the top-k entries by absolute value with k the fraction keep of the tensor's entries. A tensor missing from the base, of another shape or not floating point is named in the header's skipped, and so is a tensor with no entries unless changed_only is set. With changed_only=True, keep is a fraction of the entries that changed, so a sparse delta never spends its kept entries on zeros, and a tensor with no change, one with no entries included, is named in unchanged and costs nothing. keep outside 0 to 1 and a change that is not finite raise ValueError.
  • How a value is written. Each kept value is quantized symmetrically: its absolute value over the tensor's scale is rounded to a level from 0 to L, where L is FibonacciEncoder(n_digits).max_value and the scale puts the largest kept value at L, or is 1.0 when every kept value is 0. The default 6 digits give L = 20, so each value decodes as the scale times one of the 41 integers from −20 to 20. The value is written as a sign digit, 1 for a negative value, followed by the Fibonacci code of its level plus 1.
  • The payload. Tensor by tensor in the header's order, the n_kept gaps of its kept positions and then its n_kept values. Since the code is a prefix code, the counts alone split it.
  • The header. One JSON line with keep, n_digits, levels, which is L, each tensor's name, shape, n_kept and scale, the skipped names, and with changed_only that flag and the unchanged names. A writer may add keys of its own, as phi_rank adds round and parent to every round it ships, and decode_delta passes over them.
  • The file. save_delta writes a first line, PHID1 and the CRC-32 of every byte after that line in eight hex digits, then the header line, then the payload as 0 and 1 text, or with packed=True as bits packed eight to a byte, an eighth of the size, with their count in the header's packed_bits. load_delta refuses a file whose check line does not match, so a flipped bit is caught before it decodes as another delta; a file that starts with the header's { loads unchecked.
  • Applying it. apply_delta checks every tensor's name and shape before it writes anything, then adds each decoded value in place. A contiguous tensor takes the values through its flat view and a non-contiguous one through Tensor.put_, so a transposed tensor works. Names over one memory, as a state_dict gives a tied weight, take the delta once, and raise ValueError when the delta changes them differently.

tests/test_gaps.py holds each of these: a round trip within half a level, a delta that moves a model toward the new weights, the refusal of a truncated or extended payload, of a keep outside 0 to 1, of a change that is not finite and of a shape mismatch, an empty tensor skipped, a transposed tensor, a tied weight taking its delta once, changed_only, and the packed form with its truncation refused.

Measured on a fine-tuned transformer

The delta part of the register model's transformer check fine-tunes a character-level GPT with 4 layers of width 128, keeps the largest 10% and then 1% of each Linear layer's delta, and prices the gaps between kept positions with gap_bits. A fixed-length position there takes 16 bits, the base-2 logarithm of the largest layer's entry count rounded up.

Mean bits per kept position over the three seeds of results/transformer-check/delta.json in ezexe/p4-phi-experiments, rounded as shown:

KeptFibonacciElias gammaElias deltaFixed-lengthEntropy
10%5.155.515.9016.004.66

Its criterion K8, Fibonacci-coded gaps below both Elias gamma and a fixed-length code at 10% kept, was written before the run and survives in every seed. Fibonacci coding is the shortest of the codes compared that take no parameter, and it sits 0.49 bits per position above the entropy at 10% kept and 1.25 at 1%, and below Elias gamma by 0.37 and 1.93. A code fitted to the distribution of the gaps, such as a Golomb-Rice code with its parameter fitted, a Huffman code or arithmetic coding, can come closer to the entropy, and none was measured here.
